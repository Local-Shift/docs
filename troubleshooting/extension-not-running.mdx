If the LocalShift Chrome extension is not running or you see an error message, the problem is usually in Chrome, your connection, or your account setup. Try the fixes below to get back on track.

<AccordionGroup>
  <Accordion title="Chrome is closed or the computer is asleep">
    The extension only works while Chrome is open and your computer is awake. If either is off, the extension stops and any active posting pauses.

    **Fix:** Open Chrome and wake your computer. The extension should resume automatically within a few moments.
  </Accordion>

  <Accordion title="The extension was disabled or removed">
    Chrome updates, profile changes, or accidental clicks can disable or remove extensions.

    **Fix:** Go to **Chrome menu > Extensions > Manage extensions** and look for LocalShift. If it is off, turn it on. If it is missing, reinstall it and enter your token in the **Credentials** tab again.
  </Accordion>

  <Accordion title="Your token is missing or expired">
    The extension connects to LocalShift using a token in the **Credentials** tab. If the token is blank or outdated, the extension cannot communicate with your account.

    **Fix:** Open the extension, go to the **Credentials** tab, and re-enter your token. Then check the **Status** tab to confirm the connection is active.
  </Accordion>

  <Accordion title="Your Facebook session expired">
    The extension uses your Facebook account in a minimized window. If Facebook logs you out, the extension cannot post.

    **Fix:** Look for the minimized Facebook window and log back in. Then check the extension **Status** tab to confirm it is running again.
  </Accordion>

  <Accordion title="A Chrome update broke the extension">
    Rarely, a Chrome update can cause compatibility issues until the extension is updated too.

    **Fix:** Go to **Chrome menu > Extensions > Manage extensions**, turn on **Developer mode**, and click **Update**. Restart Chrome and check the extension again.
  </Accordion>

  <Accordion title="You see a specific error code or message">
    Some errors are temporary and clear on their own. Others point to a setup issue.

    **Fix:** Note the exact wording or code, then close and reopen Chrome. If the error returns, [contact support](/contact-support) with the details so the team can investigate.
  </Accordion>
</AccordionGroup>

If the extension still will not run after trying these steps, [contact support](/contact-support) for further help.
